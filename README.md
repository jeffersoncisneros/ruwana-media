# ruwana-media

Alojamiento público de los JPEG de los carruseles de **@ruwanaconcept**.

Existe por una restricción de la API de Instagram: al publicar, **Meta descarga
la imagen de una URL pública** — no se suben bytes y `localhost` no sirve. Este
repo es esa URL.

Lo escribe `ruwana_publish.py` del ContentDashboard. No editar a mano.
